# فحص مجلد الكتب

```bash
arabic-bib audit ~/Books
```

![فحص مجلد](../../media/audit.svg)

لكل ملف أو مجلد مخالف: علامة ✗ للخطأ و! للتنبيه، واسم القاعدة، وتفصيلها، ثم الاسم المقترح بعد السهم. وفي الآخر
خلاصة بعدد الأسماء المفحوصة والمخالفات.

## القواعد

| القاعدة | معناها |
|---|---|
| `too-long` | الاسم أطول مما يسمح به الملف (بالبايت) |
| `forbidden-char` | حرف ترفضه بعض أنظمة الملفات، مثل `:` و`?` و`*` و`"` و`/` |
| `spacing` | مسافتان متتاليتان، أو مسافة أو نقطة في أول الاسم أو آخره |
| `invisible` | حرف خفي (علامة اتجاه، وصل صفري) |
| `parentheses` | أقواس أو معقوفان |
| `comma` | فاصلة |
| `equals` | «=» بين عنوانين |
| `ta-prefix` | «ط» قبل الناشر أو رقم الطبعة |
| `hamzat-wasl` | همزة قطع على ألف وصل: «الإستغفار» |
| `presentation-forms` | أشكال عرضية من نص PDF: «ﺟﻬﺎﺩ» |
| `persian-letters` | ياء أو كاف فارسية في نص عربي |
| `tatweel` | تطويل «ـ» |
| `not-nfc` / `nfc-twin` | صورة يونيكود غير موحدة، أو اسمان لا يختلفان إلا فيها |
| `raw-name` | اسم تنزيل خام لا يدل على الكتاب: «12_3456.pdf» |
| `forbidden-word` | كلمات الرافعين («تحميل») أو علامات التكرار («نسخة ثانية») |
| `one-file-folder` | مجلد فيه ملف واحد (الكتاب المفرد ملف لا مجلد) |
| `volume-twice` | رقم مجلد مكرر |
| `numbered-99` | فهارس مرقمة 99 (رقمها يلي آخر مجلد) |

`arabic-bib profiles` يعرض القائمة كاملة مع ملفات التعريف.

## الخيارات

```bash
arabic-bib audit ~/Books --profile plain
arabic-bib audit ~/Books --only hamzat-wasl presentation-forms
arabic-bib audit ~/Books --format tsv > report.tsv
arabic-bib audit ~/Books --format json --strict
arabic-bib audit ~/Books --plan fixes.tsv
```

الخيار `--strict` يجعل الأمر يخرج برمز 1 إذا وُجد خطأ، فيصلح للتشغيل الآلي. والخطة `fixes.tsv` تبدأ بالأعمق فالأعمق
حتى يُعاد تسمية الملفات قبل مجلداتها.

!!! tip "التنفيذ الآمن"
    راجع الخطة، ثم نفّذها بأداة [planfs](/planfs/): تعرض كل تغيير قبل تطبيقه، وتحفظ سجلًا، وتتيح التراجع. وللحصول على
    قواعد التسمية نفسها في صيغة planfs: `arabic-bib profiles --planfs warraq`.
