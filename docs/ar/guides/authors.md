# أسماء المؤلفين

## أجزاء الاسم

```bash
arabic-bib author "شيخ الإسلام تقي الدين أبو العباس أحمد بن عبد الحليم بن تيمية الحراني (ت 728 هـ)"
```

| الجزء | المعنى | المثال |
|---|---|---|
| الاسم (ism) | الاسم العَلَم | أحمد |
| النسب (nasab) | سلسلة الآباء بـ«بن» | عبد الحليم، تيمية |
| الكنية (kunya) | «أبو» أو «أم» | أبو العباس |
| اللقب (laqab) | «تقي الدين»، «شيخ الإسلام»، «الجاحظ» | تقي الدين |
| النسبة (nisba) | إلى بلد أو قبيلة أو مذهب | الحراني |
| الشهرة (shuhra) | ما اشتهر به | ابن تيمية |
| الوفاة | من «ت 728 هـ» | 728 |

وتُقرأ صيغ الفهارس كما تأتي: صيغة الشاملة «المختصر؛ الكامل»، والصيغة المقلوبة «ابن خلدون، عبد الرحمن بن محمد»،
و«المعروف بـ…»، والكلمات الملتصقة مثل «أبوالحسن» و«عبدالكريم»، والألقاب مثل «الإمام» و«الحافظ» و«الدكتور» و«باشا».

## هل هما رجل واحد؟

```bash
arabic-bib match "ابن تيمية" "أحمد بن عبد الحليم بن تيمية الحراني"
arabic-bib match "ابن حجر العسقلاني" "ابن حجر الهيتمي"
arabic-bib match "محمد" "محمد بن إسماعيل البخاري"
```

الحكم واحد من ثلاثة، ومعه درجة وأسباب:

- **same (واحد)**: كل جزء في الصيغة الأقصر موجود في الأطول، وفيها جزء مميز واحد على الأقل.
- **different (اثنان)**: سنتا وفاة متباعدتان، أو اختلاف في الاسم أو الأب أو الكنية أو اللقب، أو نسبتان مميزتان لا تلتقيان،
  أو شهرتان مختلفتان.
- **unknown (لا يُعرف)**: لا يستند التوافق إلا إلى أجزاء شائعة مثل «محمد» و«شمس الدين» و«الدمشقي».

```python
from arabic_bib import match_authors

m = match_authors("ابن القيم", "محمد بن أبي بكر بن أيوب ابن قيم الجوزية")
m.verdict, m.reasons    # ('same', ('shuhra:ابن القيم',))
```

!!! note "الأجزاء الشائعة في فهرسك"
    ما يُعد شائعًا يختلف من فهرس إلى آخر. أضف ما يكثر في فهرسك بالخيار `common`:
    `match_authors(a, b, common=["الذهبي"])`.

## المحققون والناشرون

`same_person` تقارن صيغتين لاسم محقق معاصر، و`same_publisher` تقارن ناشرين، وتعرف بعض المطابع التي اشتهرت بأكثر من اسم
(بولاق والمطبعة الأميرية، ومطبعة مصطفى البابي الحلبي، ودائرة المعارف العثمانية بحيدر آباد).
