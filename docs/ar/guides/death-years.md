# سنوات الوفاة والتقويم الهجري

## قراءة الوفاة

```bash
arabic-bib date "ابن تيمية (ت 728 هـ)"
arabic-bib date "المتوفى سنة ثمان وعشرين وسبعمائة"
arabic-bib date "الذهبي (673 - 748 هـ)"
arabic-bib date "ت بعد 666 هـ"
arabic-bib date "من علماء القرن الحادي عشر"
```

| الصيغة | الناتج |
|---|---|
| ت 728 هـ، ت. ٧٢٨هـ، المتوفى: 728هـ | 728 |
| توفي سنة ثمان وعشرين وسبعمائة | 728 (العدد بالحروف) |
| (673 - 748 هـ) | الوفاة 748، والولادة 673 |
| 728 هـ / 1328 م | السنة بالتقويمين |
| ت بعد 666 هـ، نحو 450 هـ، في حدود 500 | السنة مع وصف التقريب |
| القرن الثامن الهجري، ق 8 هـ | القرن 8 |
| معاصر، حفظه الله | على قيد الحياة |

ولا يُعد العدد المجرد سنة وفاة إلا إذا سبقته كلمة دالة («ت»، «توفي»، «المتوفى») أو تبعته علامة التقويم أو كان بين
قوسين، فلا تُقرأ «دار الفكر 1985» وفاةً.

## التحويل بين التقويمين

```bash
arabic-bib hijri 728
arabic-bib hijri 728-11-20
arabic-bib gregorian 1999
arabic-bib gregorian 1979-11-21
```

```text
728 هـ = 1327–1328 م
728-11-20 هـ = 1328-09-26 م
1999 م = 1419–1420 هـ
1979-11-21 م = 1400-01-01 هـ
```

يجري التحويل بالتقويم الهجري الحسابي (الجدولي) الذي تعتمده كتب المراجع: دورة من ثلاثين سنة كبيستها 2 و5 و7 و10 و13
و16 و18 و21 و24 و26 و29، وأولها الجمعة 16 يوليو 622 م. وقد يخالف التاريخ الفعلي يومًا أو يومين لأن الشهر كان يثبت برؤية
الهلال.

!!! tip "التقويم اليولياني"
    التواريخ الميلادية قبل 15 أكتوبر 1582 تُعطى باليولياني كما يكتبها المؤرخون: وفاة ابن تيمية 20 ذي القعدة 728 هـ =
    26 سبتمبر 1328 م. والخيار `--proleptic` يعطي الغريغوري الممتد إلى الوراء (4 أكتوبر 1328).

ولتقويم أم القرى (1343–1500 هـ) ثبّت `arabic-bib[umalqura]` واستعمل `--calendar umalqura`.
