# بيانات الطبعة

```bash
arabic-bib edition "الطبعة الأولى، دار الكتب العلمية، بيروت، 1420 هـ - 1999 م"
arabic-bib edition "تحقيق: شعيب الأرنؤوط - مؤسسة الرسالة، بيروت، ط 2، 1405هـ/1985م"
arabic-bib edition "دار ابن حزم - بيروت - لبنان - ط1 - 2003"
```

تُقرأ كل قطعة بما هي، لا بموضعها في السطر:

| القطعة | تُعرف بـ |
|---|---|
| رقم الطبعة | «الطبعة الأولى»، «ط 2»، «ط1»، «الطبعة الخامسة عشرة» |
| المحقق وصفته | «تحقيق»، «حققه وعلق عليه»، «اعتنى به»، «ضبط المتن» |
| مشاركون آخرون | «قدم له»، «ترجمة»، «ترقيم» |
| الناشر | يبدأ بـ«دار»، «مكتبة»، «مؤسسة»، «مطبعة»، «وزارة»، «جامعة»، «مركز» … |
| المدينة والبلد | من قائمة بمدن النشر العربية والمطابع المشهورة (بيروت، القاهرة، بولاق، حيدر آباد، ليدن …) |
| السنة | «1420 هـ» هجرية، «1999 م» ميلادية، والعدد المجرد يُحكم عليه بمقداره |
| نوع الطبعة | «طبعة حجرية»، «طبعة مصورة»، «مصورة عن …» |

وبطاقات الفهارس ذات الأسطر «الناشر: …» و«الطبعة: …» و«المحقق: …» تُقرأ كذلك. وما لم يُعرف من القطع يُحفظ في الحقل
`rest` ولا يُهمل.

```python
from arabic_bib import parse_edition

e = parse_edition("الطبعة الأولى، دار الكتب العلمية، بيروت، 1420 هـ - 1999 م")
e.number, e.publisher, e.city, e.country, e.hijri, e.gregorian
# (1, 'دار الكتب العلمية', 'بيروت', 'لبنان', 1420, 1999)
```
