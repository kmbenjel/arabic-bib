# التثبيت

تحتاج arabic-bib إلى بايثون 3.10 أو أحدث، ولا تعتمد على أي مكتبة أخرى؛ حجمها نحو ميغابايت واحد.

## لاستعمال الأداة من سطر الأوامر

الطريقة الأيسر هي `pipx`، فهو يضع الأداة في بيئة مستقلة ويجعل الأمر `arabic-bib` متاحًا في كل مكان:

```bash
pipx install arabic-bib
```

ويمكن تجربتها دون تثبيت بواسطة `uv`:

```bash
uvx arabic-bib demo
```

## لاستعمالها مكتبةً في برنامجك

```bash
pip install arabic-bib
```

ثم:

```python
from arabic_bib import search_key, parse_author, match_authors, parse_death
```

## الإضافة الاختيارية: تقويم أم القرى

التحويل بين التقويمين يجري افتراضيًا بالتقويم الهجري الحسابي (الجدولي) المعتمد في كتب المراجع. فإن أردت تقويم أم القرى
للسنوات من 1343 إلى 1500 هـ فثبّت الإضافة:

```bash
pip install "arabic-bib[umalqura]"
```

## التحقق من التثبيت

```bash
arabic-bib --version
arabic-bib demo
```

!!! tip "ويندوز وماك ولينكس وأندرويد"
    المكتبة مكتوبة ببايثون الخالص، فتعمل حيث تعمل بايثون، ومن ذلك Termux على الهاتف.
