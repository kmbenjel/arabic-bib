# البدء السريع

## 1. العرض التوضيحي

```bash
arabic-bib demo
```

ينشئ هذا الأمر مجلدًا مؤقتًا فيه عشرة كتب بأسماء مخالفة، ويفحصها، ثم يعرض تركيب اسم كتاب، وتفكيك اسم ابن تيمية، والحكم
على ثلاث صيغ لأسماء المؤلفين، وقراءة سني الوفاة وبيان الطبعة. ولا يغيّر شيئًا في جهازك.

![العرض التوضيحي](../media/demo.svg)

## 2. افحص مجلد كتبك

```bash
arabic-bib audit ~/Books
```

لكل اسم مخالف تظهر المخالفات ثم الاسم المقترح بعد السهم. لا يُعاد تسمية أي ملف: الفحص قراءة فقط. وإن أردت خطة
لإعادة التسمية تراجعها قبل التنفيذ:

```bash
arabic-bib audit ~/Books --plan fixes.tsv
```

الملف `fixes.tsv` ثلاثة أعمدة: الاسم الحالي، والاسم الجديد، والسبب. افتحه في أي محرر جداول، واحذف ما لا تريده، ثم
نفّذه بأداة [planfs](/planfs/) التي تعرض التغييرات قبل تطبيقها وتسجلها وتتيح التراجع عنها.

## 3. ركّب اسم كتاب

```bash
arabic-bib compose -t "الرسالة" -a "الشافعي" -e "تحقيق أحمد شاكر، مكتبة الحلبي، القاهرة" --ext
```

```text
الرسالة - الشافعي - ت أحمد شاكر - مكتبة الحلبي القاهرة.pdf
```

## 4. اسأل عن مؤلف

```bash
arabic-bib author "شيخ الإسلام تقي الدين أبو العباس أحمد بن عبد الحليم بن تيمية الحراني (ت 728 هـ)"
arabic-bib match "ابن تيمية" "أحمد بن عبد الحليم بن تيمية الحراني"
```

## 5. اقرأ تاريخًا أو بيان طبعة

```bash
arabic-bib date "المتوفى سنة ثمان وعشرين وسبعمائة"
arabic-bib hijri 728
arabic-bib edition "الطبعة الأولى، دار الكتب العلمية، بيروت، 1420 هـ - 1999 م"
```

لكل أمر الخيار `--json` لإخراج قابل للمعالجة الآلية، و`arabic-bib --help` يعرض الأوامر كلها بأمثلتها.
